# Sort & Build 3D

Мобильная головоломка: сортируешь материалы по полкам, собираешь тройки —
на острове растёт город. 627 уровней в 30 мирах, 19 языков, режимы 2D и 3D.

## Запуск

```bash
npm install
npm run dev          # откроется на localhost:5173
npm run dev -- --host   # чтобы открыть с телефона в той же сети
npm run build        # сборка в dist/
```

## Механика

Полки по три места. Предмет перетаскиваешь между полками; три одинаковых
на одной полке уезжают на стройку. Когда полка полностью пустеет, из её
глубины выходят предметы, стоявшие сзади.

Осложнения (появляются постепенно): джокер, запертая полка, лёд на месте,
загадка, закреплённый предмет, полка с лимитом материала, сцепка.

## Важные решения — не сломать при доработке

**Проходимость.** Поле строится обратными ходами от собранного состояния,
затем проверяется решателем. Если решения нет — поле пересобирается, а в
крайнем случае упрощается. Никогда не возвращай поле без проверки: именно
такой возврат когда-то и был источником нерешаемых уровней.

**Правила игры и решателя должны совпадать.** Был баг: решатель считал,
что собранная тройка растапливает лёд, а игра — нет. Уровни признавались
проходимыми по правилам, которых в игре не существовало. При любой правке
механики проверяй обе стороны.

**Лёд замораживает МЕСТО, а не предмет.** Замороженный предмет запирает
полку насмерть — тройка собирается целиком, растопить его можно только
другой тройкой, а места он не освобождает. Даёт 100% непроходимых полей.

**Сумма источников света не должна превышать 1.0.** Иначе цвета
обрезаются в белый: постройки выцветают, модели теряют объём. Проверено
дважды — в сцене мира и в сцене поля.

**Ортографическая камера на поле.** При перспективе нижние полки дальше
и выглядят на 10% мельче — читается как перекос.

**group.add(mesh) возвращает группу, а не меш.** Запись вида
`g.add(put(деталь, x, y, z)).rotation.x = ...` разворачивает всё здание
целиком. Так восемь построек оказались вверх ногами.

**Пополнение полки — при любом опустошении**, а не только после сборки
тройки. Иначе полка, опустевшая из-за переноса, запирает свою глубину
навсегда.

## Что ещё не сделано

- `buyWorld` и `buyIAP` — заглушки, выдают покупку бесплатно.
  Нужен StoreKit через Capacitor.
- `showAd` — заглушка на таймере. Нужна медиация (AppLovin MAX или
  Unity LevelPlay) с наградным видео.
- Музыки нет, только синтезированные звуки.
- Генерация тяжёлого уровня доходит до ~1 секунды. На слабом телефоне
  заметно — стоит вынести в Web Worker.

## Сборка под iOS без Mac

`codemagic.yaml` в корне настроен под Codemagic — он поднимает Mac в
облаке, собирает и подписывает. Нужен аккаунт Apple Developer ($99/год),
своего Mac не требуется.

Перед первой сборкой: заменить `com.example.sortandbuild` на свой
идентификатор в `capacitor.config.json` и `codemagic.yaml`, указать почту
для уведомлений.
