ЧТО ГДЕ ЛЕЖИТ
=============

В этом архиве:

  codemagic.yaml   → в КОРЕНЬ репозитория (рядом с папкой proj)
  proj/            → сама папка проекта, заменяет старую proj целиком


КУДА КОПИРОВАТЬ
===============

Должно получиться так:

  SORT FOR BUILD/          ← папка репозитория
  ├── .git/
  ├── codemagic.yaml       ← отсюда, из архива
  └── proj/                ← отсюда, из архива
      ├── src/
      ├── package.json
      ├── index.html
      └── ...

ВАЖНО: node_modules НЕ трогать — она остаётся твоя, в архиве её нет.
Папки ios/ и android/ тоже не нужны: Codemagic создаёт их сам при сборке.


ПОРЯДОК ДЕЙСТВИЙ
================

1. Заменить papку proj и файл codemagic.yaml из архива
2. GitHub Desktop → Commit → Push origin
3. Codemagic → Start new build → Android

Локально ничего пересобирать не нужно: Codemagic делает npm install
и npm run build сам на своей стороне.


ЧТО ИСПРАВЛЕНО В ЭТОЙ ВЕРСИИ
============================

Игра застревала на заставке с ошибкой "readSave is not defined".
Функции чтения и очистки сохранения не экспортировались из
core/save.js и не импортировались в App.jsx — при разбивке на
модули скрипт их пропустил, потому что они вызываются внутри
асинхронной функции.

Проверено: все 29 модулей просканированы на такие же пропуски,
других нет.
